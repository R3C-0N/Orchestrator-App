# Fixtures stream-json (claude 2.1.325, Windows 11)

Toutes les captures viennent d'un pilote Node de test (hors dépôt) qui lance `claude.exe`, écrit des messages JSON sur stdin et recopie stdout ligne à ligne. Les lignes préfixées `>>> ` sont les envois du pilote, `EXIT n` et `STDERR ` sont ajoutées par lui ; tout le reste est la sortie du CLI. Les arguments de lancement ne figurent pas dans les captures : les lignes de commande ci-dessous sont reprises du code du pilote et des commandes utilisées, sans reconstitution.

Dans toutes les captures : les champs `signature` des blocs `thinking` sont `REDACTED` ; le nom d'utilisateur Windows est remplacé par `<user>` (`C:\Users\<user>`), le dossier temporaire de session par `<session>` ; `account.email`, `account.organization` et `subscriptionType` sont `REDACTED`. Dans `t1`, le chemin de l'outil Read, qui arrivait en fragments `input_json_delta`, a été recollé dans le premier fragment (les suivants sont vides) pour pouvoir être neutralisé. Il n'y a pas de `t2` (numérotation d'origine conservée).

Commande de base commune : `claude.exe -p --input-format stream-json --output-format stream-json --verbose` + les options indiquées.

Deux tours dans un même processus ; montre `system/init` complet (rapporte `"permissionMode":"default"` pour `manual`), `hook_*`, deltas `text_delta` / `input_json_delta`, `tool_use` Read, `tool_result`, `rate_limit_event`, `result`.
